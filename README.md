# Adamu Yola Foundation website

Official website of the Adamu Yola Foundation, Gombe State, Nigeria.
Live at **https://adamuyolafoundation.org** (also served at https://seyidev-ops.github.io/ayf/).

*Education, Entrepreneurship and Youth Development.*

Static site (HTML, CSS, vanilla JS) served by GitHub Pages. No build step is needed to publish.

## Structure
- Pages: `index.html`, `about.html`, `programs/` (five programmes and Past Initiatives), `news.html`, `gallery.html`, `get-involved.html`, `contact.html`, `privacy.html`, `terms.html`, `404.html`. `stories.html` redirects to `news.html`.
- Styles: `assets/site.css`. Interactions (theme toggle, menus, filters, lightbox, contact form): `assets/site.js`.
- Brand (2026 logo): `assets/brand/` holds the layered animated mark (`mark/`), wordmarks and favicons.
- Programme badges: `assets/unity-cup-badge*.webp` (10th anniversary) and `assets/principals-cup-crest*.webp`.
- Event photos: `assets/photos/` (see `PHOTO_ARCHIVE_STATUS.md`).
- Share image: `assets/og-image.jpg` (1200x630, used by every page for link previews). `assets/social-preview.png` (1280x640) is the same artwork for the GitHub social preview.

## How the pages are made
Pages are generated by `tools/build.py`, which holds the navigation, programmes, news and gallery data. To change content, edit that file and run:

```bash
python3 tools/build.py
```

Then commit the regenerated HTML. Details for contributors and for Claude are in [`CLAUDE.md`](CLAUDE.md).
